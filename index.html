Protection des données

Protection des données — Les données de localisation sont systématiquement effacées lors de chaque connexion depuis un appareil. Si vous souhaitez vous assurer que vos données ont bien été effacées, vous pouvez adresser votre demande à l'adresse suivante : dimosai@hotmail.fr.

Mentions légales

Application gratuite et communautaire. Les liens renvoient vers les sites des organismes concernés. La responsabilité éditoriale des informations propres à chaque structure reste celle de l’organisme cité.

📋 Mentions légales

Cet espace, vide par défaut, vous appartient : renseignez-y par exemple les mentions légales (éditeur, directeur de publication, hébergeur), une politique de confidentialité complète, ou toute autre information réglementaire propre à votre structure. 🎨 Personnaliser l'application

Ces réglages remplacent le titre, le sous-titre et les couleurs par défaut de l'application. Ils sont enregistrés sur cet appareil ; pour les diffuser à tous, réenregistrez le fichier HTML après les avoir définis (bouton « ⬇ Télécharger la-maraude-connectee.html »).
